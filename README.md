# Multi-AI

複数の AI サービスの既存 Web 画面を、一つのウィンドウ内に並べて使うためのデスクトップアプリケーションです。

AI API を共通化するのではなく、ChatGPT、Claude、Gemini など、利用者が契約・利用している Web 版サービスを「一つの作業机」にまとめることを目指します。現在は要件整理を終え、最小版の実装に着手する前の段階です。

## 最初に目指すもの

- 2 分割・4 分割で複数の AI サービスを同時表示する
- 各画面を通常のブラウザと同様に直接操作できる
- ログイン状態、選択したサービス、レイアウトを保持する
- 戻る、進む、再読み込み、ズーム、画面の一時最大化を提供する
- 用途ごとの画面構成をワークスペースとして保存する

初期版では、同一プロンプトの自動一括送信や、各サービスの画面構造に依存する操作自動化は対象外です。

## セットアップ

Node.jsとnpmを用意し、`npm ci` を実行します。詳細は [`OPERATIONS.md`](OPERATIONS.md) を参照してください。

## 起動方法

`npm start` でbuild後のElectronアプリを起動します。

## 環境変数

必要な環境変数はありません。
