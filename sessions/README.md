# 作業セッションログ

AI または開発者が実際に行った作業を、1 セッションにつき 1 ファイルで記録します。

## ファイル名

`YYYY-MM-DD-short-task.md` の形式を使います。同日・同名の作業が複数ある場合は、末尾に連番を付けます。

## 必須項目

- 目的
- 調査したこと
- 変更したファイル
- 実装内容
- 発生した問題
- 解決方法
- 実行した検証
- 残っている問題
- 次回への引き継ぎ

ここは作業履歴の保管場所です。現在の状態は `CURRENT.md`、現行構成は `ARCHITECTURE.md`、利用方法は `README.md` を更新し、同じ説明をここへ複製し続けないでください。
